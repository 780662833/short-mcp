# 分镜生成规则：对白可执行性与 AI 素材准备

生成《拆弹夫妻》这类 15 秒竖屏快节奏喜剧时，必须遵守：

1. 每个镜头的台词必须能在该镜头 `duration` 内说完：按约 5 个汉字/字母/数字每秒估算（不计标点和角色名），每次换人说话额外预留 0.3 秒。
2. 一个镜头最多 1 次对话往返（最多两段角色发言）；动作密集的镜头只保留一句台词，其余信息交给字幕、画面和音效。
3. 关键视觉反转（如素颜登场、肚子弹出）优先于台词完整度：该镜头台词可以压缩到 1–4 个字，甚至完全无台词。
4. 输出前逐镜头计算台词时间；任何镜头估算超时，都应在生成阶段精简对白、拆分镜头或调整时长，并由创作者确认最终剧本。
5. 字幕不是口播的自动替代品：只有明确写入 `subtitle` 的信息才算字幕；不要为了保留对白而把同一句话重复写进台词和字幕。
6. 15 秒成片优先保证视觉动作、反转和观众理解。若无法同时保留全部信息，应删减次要对白，不得假设演员能超速说完。
7. `scene` 应清楚描述本镜头的可见内容，包含人物、动作、景别/构图、环境及必要的光线/镜头运动信息。它是生成 `prompt` 的语义来源，不应在转写提示词时改变关键剧情。
8. 每个镜头必须包含素材字段：`source`（`ai` 或 `shoot`，默认 `ai`）、`prompt`（目标模型提示词，可在提示词尚未制作时留空）、`ref_image`（角色参考图路径，可暂留空）、`seed`（可选整数，未指定用 `null`）和 `clip`（生成后素材路径）。
9. AI 生成镜头应优先使用统一角色参考图，描述角色外观、服装、动作、场景、景别、构图、光线和风格；同一角色跨镜头保持身份特征一致。只有目标生成模型支持并且有复现需要时才固定 `seed`。
10. JSON 必须符合仓库中的 schema：时间轴连续、镜头编号连续、总时长准确，每条字幕不超过 12 个字符；不得增加未定义字段。

## 输出前自检

- 列出每个镜头的 `duration`、对白有效字数、发言段数和估算所需秒数。
- 逐镜头核对 `estimated_speech_seconds <= duration + 0.01`。
- 核对 `source` 值是否合法；确认 `prompt`、`ref_image`、`seed` 是已知值，未确定的值使用空字符串或 `null`，不要编造不存在的文件路径。
- 确认 `scene` 中的动作顺序和关键反转在 `prompt` 中得到保留。
- 最终只输出满足 schema 的 JSON；自检表可放在 JSON 之外的说明中，不要塞入 JSON 未定义字段。

## 当前阶段边界

当前工作聚焦于分镜数据结构、提示词准备和后续 AI 素材生成接口所需的字段。暂不实现 Agent 自动运行校验器、自动回传错误或自动重新生成剧本的闭环；校验器只作为可单独运行的静态校验工具。
