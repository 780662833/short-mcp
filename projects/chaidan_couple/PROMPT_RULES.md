# 分镜生成规则：对白可执行性

生成《拆弹夫妻》这类 15 秒竖屏快节奏喜剧时，必须遵守：

10. 每个镜头的台词必须能在该镜头 `duration` 内说完：按约 5 个汉字/字母/数字每秒估算（不计标点和角色名），每次换人说话额外预留 0.3 秒。
11. 一个镜头最多 1 次对话往返（最多两段角色发言）；动作密集的镜头只保留一句台词，其余信息交给字幕、画面和音效。
12. 关键视觉反转（如素颜登场、肚子弹出）优先于台词完整度：该镜头台词可以压缩到 1–4 个字，甚至完全无台词。
13. 输出前逐镜头计算台词时间；任何镜头估算超时，都必须先删减台词、拆分镜头或调整时长，再输出最终 JSON。
14. 字幕不是口播的自动替代品：只有明确写入 `subtitle` 的信息才算字幕；不要为了保留对白而把同一句话重复写进台词和字幕。
15. 15 秒成片优先保证视觉动作、反转和观众理解。若无法同时保留全部信息，应删减次要对白，不得假设演员能超速说完。
16. 生成的 JSON 必须符合仓库中的 schema，不得增加未定义字段；时间轴连续、镜头编号连续、总时长准确，每条字幕不超过 12 个字符。

## 输出前自检

- 列出每个镜头的 `duration`、对白有效字数、发言段数和估算所需秒数。
- 逐镜头核对 `estimated_speech_seconds <= duration + 0.01`。
- 有任何一镜不通过时，先修改剧本并重新自检，不要输出未通过的最终版本。
- 最终只输出满足 schema 的 JSON；自检表可放在 JSON 之外的说明中，不要塞入 JSON 未定义字段。
